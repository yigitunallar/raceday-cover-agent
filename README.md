# raceday-cover-agent

A hackathon demo of an agent that arranges synthetic race-day horse cover and safely recovers from interrupted payments and policy actions.

## Status

Design drafts are in [`docs/superpowers/specs`](docs/superpowers/specs/). Implementation has not started. The demo uses synthetic data and mocked race, payment, policy, insurer, and notification systems; it must not connect to real customers or payment services.
